Read first: how to judge

Compare the current anchor value with the value, tier and group of every source below:
  1. no_change: new value equals the old one (ignore commas, currency symbols and a leading v)
  2. reject: unreliable source (T3/T4), unreachable, or older than the current value
  3. review: only one authoritative source, conflicting sources, unclear units or periods, or you are unsure
  4. auto_update: at least two independent T1/T2 sources agree on the same new value
Sources in the same group count as one; when unsure, choose review instead of guessing.
