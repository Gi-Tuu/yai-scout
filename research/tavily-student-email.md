# Tavily 学生认证邮件（可直接复制）

> 官方要求（原文）：从**学校官方邮箱**发邮件到 support@tavily.com，**或**把**学生证照片**发给 support 团队。
> 官方页面：https://help.tavily.com/articles/6606514713-student-account
> 通过后会收到 **coupon code**；到 [Billing](https://app.tavily.com/billing) → Project Plan → Upgrade → **Add Promotion Code** 兑换（4 个月 × 4,000 credits/月）。

## 方案 A：用学校邮箱发送（推荐，最简单）

- **收件人**：support@tavily.com
- **发件人**：你的 `@学校域名` 邮箱
- **Subject**：

```text
Student verification request – Project Plan (4,000 credits/month) – [Your Name]
```

- **正文**：

```text
Hi Tavily support team,

I would like to verify my student status to claim the free 4-month Project Plan
(4,000 API credits per month) for students.

Details:
- Name: [Your full name]
- University: [University name]
- Program / Degree: [e.g., BSc Computer Science, MSc AI]
- Year / Expected graduation: [e.g., Year 3, expected 2027]
- Tavily account email: [the email you use at app.tavily.com]
- Use case: building a research-agent benchmark and a stale-answer detector for
  the Geek Room Global AI Hackathon 2026 (Nov 1–15). The credits will be used for
  live web verification and benchmark evaluation.

I am sending this from my official university email address: [your school email].

Could you please verify my student status and send me a promotion code?

Thank you!
[Your name]
```

## 方案 B：用个人邮箱 + 学生证

- 收件人、Subject 同上；
- 正文里加一句："I have attached a copy of my student ID."；
- 附件：学生证照片/扫描件。
- **隐私建议**：遮住学号、住址、身份证号等无关信息，只保留**姓名、学校、专业、有效期**（审核只需要这些）。不要发护照/身份证。

## 跟进（3–5 个工作日没回复时）

```text
Subject: Re: Student verification request – [Your Name]

Hi Tavily support team,

Just following up on my student verification request sent on [date].
I'm happy to provide any additional information needed.

Thank you!
[Your name]
```

## 通过后

1. 收到 coupon code；
2. 登录 https://app.tavily.com/billing；
3. Project Plan → Upgrade → **Add Promotion Code** → 粘贴兑换；
4. 确认账户显示 4,000 credits/月（4 个月）；
5. 把额度用途记到 `docs/api-resources.md`：**这是学生计划额度，不是赛事奖励 credits**。
