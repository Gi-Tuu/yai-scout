# 主办方回复存档

把主办方的邮件原文 / 截图放在这个目录，命名建议：

```text
2026-11-01-organizer-reply-all-yes.txt   # 第一封回复（All yes）
2026-11-0X-organizer-reply-submission.md # 第二封回复（提交机制/credits）
```

要求：
- 保留发件人、收件时间、邮件正文；
- 截图请存 PNG/JPG，并在同目录写一个 `.md` 摘录关键句；
- 不要包含个人隐私（手机号、地址）之外的无关信息；
- 更新 `research/organizer-reply.md` 的结论与 `docs/hackathon-rules-report.md` 的规则状态。
