# Engineering Governance Audit — 2026-11-01

Baseline: `main` @ `b509da1` (v0.1.0-hackathon). Audit was read-only; fixes were then applied on
branch `governance/engineering-v1` and are marked below. Evidence is from source inspection and the
existing test suite, not from unverified assumptions.

## D. Already-correct areas (verified, no change)

- `domain/models.py` has no infra imports (pydantic only).
- `detector/*` does not import `benchmark/*`; dependency is one-way (`benchmark → detector.service`).
- YAI integration is isolated in `kernel/yai_adapter.py`; no other module imports `yai_core`.
- Adapter protocol validates request/response shapes and is covered by HTTP/Python/CLI contract tests.
- Historical detector reports with stored versions remain readable; no rewrite on read.
- Two-container `SCOUT_MODE` isolation test exists.

## E. Test coverage delta

Before: 74 tests (no manifest, result hash, hidden API isolation, stable metric, version consistency,
legacy migration, immutability tests).

After: **93 tests** (19 governance tests added + runner manifest assertions), plus the same suite on
Python 3.11 and 3.12.

## F. Out of scope / not changed

- Freshness weights/rules (no algorithm change; only version reporting).
- Benchmark ranking formula.
- Dataset content (only added `compromised` metadata to hidden tasks).
- Public API shapes except removing the insecure `include_hidden` parameter and adding a verify
  endpoint.
- No push, merge, release or deployment in this branch.
