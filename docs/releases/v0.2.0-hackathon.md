# YAI Scout v0.2.0 — Engineering Governance & P0 Hardening

This release contains **no change to freshness scoring rules or benchmark ranking weights**. It
makes the existing behavior reproducible, isolated and auditable.

## Highlights

- **Experiment Manifest**: every benchmark run records dataset/task hashes, agent manifests,
  model/protocol/tool/budget/timeout configuration, evaluator/policy/weights/prompt versions,
  code commit, dependency-lock hash and snapshot IDs. `config_hash` is canonical and
  order-independent; `result_hash` is stored once at completion.
- **Result verification**: `GET /benchmark/runs/{id}/verify` recomputes the result hash.
- **Immutable runs**: completed sessions are append-only; revisions use `supersedes`.
- **Hidden dataset isolation**: public API/loader never returns hidden tasks; the runner rejects
  hidden IDs unless an explicit private context is used. The three previously committed hidden
  tasks are marked `compromised` — they are not claimed to be secret.
- **Metric correctness**: `stable_fact_integrity` counts only genuinely STABLE claims, joined by
  claim ID (returns `null` when not evaluable).
- **Version truth**: single policy/weights version source; legacy reports missing versions load as
  `unknown` rather than being silently assigned the current version.
- **Python support**: 3.11 and 3.12 are both tested in CI; the one PEP 695 generic was removed.
- **Governance docs**: Engineering Governance v1.0, ADR-0003, P1 backlog and the read-only audit
  report are in `docs/`.

## Verification

- 93 tests on Python 3.11 and 3.12
- `ruff` and `mypy --strict` clean
- Docker image builds (`docker build -t yai-scout:governance .`)
- API smoke: public dataset 21 tasks, hidden run returns 400, result hash verify matches
- Live demo: <https://yai-scout.onrender.com> (free tier; first request after idle may take 30–90s)

## Compatibility notes

- **API**: the `include_hidden` query parameter was removed (security fix). All other benchmark
  endpoints keep their paths. `/benchmark/runs/{id}/verify` is new.
- **SQLite**: additive migration only (`manifest_json`, `result_hash`, `supersedes` columns);
  historical rows remain readable.
- **Historical reports**: missing `policy_version`/`weights_version` fields load as `unknown`.
- **Dataset**: version bumped to `freshness-bench/0.2.1` because hidden metadata added
  `compromised: true`; task content is unchanged.

## Known limits

- Private replacement questions are not included in this public repository.
- `result_hash` covers result summaries, not the full evidence graph.
- Public demo has no rate limiting yet (P1).
- Web-archive replay remains limited to GitHub release history; Wayback is unreachable from the
  current network.
