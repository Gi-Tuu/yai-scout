# YAI Scout v0.2.1 — Public Demo Cost Guard

Small hardening release after v0.2.0. No changes to freshness scoring or benchmark ranking.

## Added

- Cost protection for the public demo:
  - global per-minute cap (default **4 requests/min** across all clients),
  - per-IP per-minute cap,
  - daily caps for detector (**60/day**) and benchmark (**20/day**),
  - `429` with `Retry-After` when exceeded,
  - live usage exposed in `GET /api/healthz` → `limits`.
- All thresholds configurable by environment (`RATE_LIMIT_PER_MINUTE`,
  `DAILY_DETECTOR_LIMIT`, `DAILY_BENCHMARK_LIMIT`, `DEMO_LIMITS_ENABLED`).

## Fixed

- Per-minute limit is enforced globally, not only per client, so rotating
  `X-Forwarded-For` cannot bypass the cap.

## Verified

- 98 tests, ruff + mypy strict clean, Docker build passes.
- Online: five rapid hidden-task requests → 4 × `400` + 1 × `429`; usage counter stops at 4.
- `/api/healthz` exposes limits; replay and hidden isolation still work.

## Notes

Counters are in-process and reset on restart. This is suitable for a single free Render instance,
not a multi-instance production deployment.
