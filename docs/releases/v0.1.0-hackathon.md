# YAI Scout v0.1.0 — Hackathon Preview

Two independent projects, one evidence core, built for **Geek Room Global AI Hackathon 2026**:

- **YAI Scout Benchmark** — Bifrost Track, Problem 02 (*Build a benchmarking platform for AI agents, not just models*)
- **YAI Scout Freshness** — Tavily Track, Problem 01 (*Stale-answer detector*)

## Highlights

- **Claim-level freshness**: LLM claim extraction (quote-substring validated) + Tavily live verification + temporal-sensitivity decision table + explainable score breakdown + correction suggestions.
- **Cross-architecture benchmark**: `scout-adapter/1.0` HTTP protocol, Python in-process and CLI subprocess adapters; multi-dimensional leaderboard with a Pareto frontier.
- **24-task dataset** (21 public + 3 hidden) across stable / time-sensitive / changed / conflicting facts.
- **Evidence Inspector** (`/inspector`): claim → sources → timestamps → relation → score breakdown.
- **Real temporal replay** from GitHub Releases official history: YAI `0.25.0` is **STALE at 2026-10-28** and **FRESH at 2026-11-01** (delta +64). Replay is explicitly labelled `simulated` when no real snapshot exists.
- **Two-container deployment** (`benchmark` / `freshness`), `SCOUT_MODE` isolation verified.

## Verification

- 73 tests, ruff, mypy strict — all green.
- CI (lint + types + tests + Docker build): https://github.com/Gi-Tuu/yai-scout/actions
- Docker: `docker compose up -d --build` → `:8010` (benchmark) / `:8011` (freshness)

## Quick start

```bash
uv sync --extra dev
cp .env.example .env      # optional keys; keyless / rule-based fallbacks exist
uv run uvicorn yai_scout.api.app:app --port 8010
```

## Known limits (honest)

- Web-archive (Wayback) is unreachable from the build network; replay currently covers GitHub release history, not arbitrary web pages.
- Freshness calibration set: 20 rule-labelled claims (status 20/20, MAE 12.06); human scoring of 60 claims pending.
- Benchmark dataset is small and scoped to the AI-developer ecosystem — a demo benchmark, not an academic leaderboard.
